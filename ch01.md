# Inleiding

## Aanleiding

Overheidsstandaarden zijn geschreven voor mensen: proza met tabellen en diagrammen. AI-agents die software bouwen of data verwerken, moeten de regels daaruit zelf afleiden. Dat gaat mis: een verkeerde versie, een verkeerd gelezen regel, verzonnen onderdelen. En als een standaard wijzigt, weet niemand automatisch welke software moet worden aangepast.

## Doel

- **AI Ready Standaarden.** Naast de publicatie voor mensen komt een publicatie voor AI-agents: formele modellen (MIM, OWL met SHACL, JSON Schema), een standaardenmanifest, skills (instructiebestanden voor agents), validators met goede en foute voorbeelden en MCP-services waarmee een agent een standaard kan aanroepen.
- **CompliancePush.** Een systeem dat publieke overheidsrepositories vindt die een standaard implementeren en bij een wijziging automatisch een wijzigingsvoorstel aanbiedt.

Het project is geslaagd als AI-agents aantoonbaar beter presteren met AI-ready standaarden dan met de oorspronkelijke documentatie.
